# Refresh visual Rumo com Zoom Out

Esta versão aplica ao Leitor iAuditor o mesmo padrão visual usado nos demais sites do Hub de Qualidade.

## Ajustes realizados

- Inclusão dos assets oficiais Rumo em `assets/brand`.
- Favicon e logo Rumo aplicados localmente.
- Interface com escala reduzida para exibir mais conteúdo na tela.
- Topbar, sidebar, hero, cards, upload, histórico, tabelas, botões e badges compactados.
- Paleta visual alinhada ao padrão Rumo: azul institucional, amarelo, verde e azul claro.
- Grafismos sutis de movimento no fundo.
- Cache bust no CSS/JS para facilitar atualização no GitHub Pages.

## O que foi preservado

- Leitura de PDF via PDF.js.
- Parser do iAuditor.
- Histórico local no navegador.
- Exportação CSV.
- Todas as regras de negócio do sistema.
